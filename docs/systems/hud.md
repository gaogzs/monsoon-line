## 各元素说明

### 油门（单一控制轴）

油门是 **0 – 1.25** 的一条轴：

- `0 – 1.0`：常规推力区，HUD 上 80% 处有一道白线标出军推上限
- `1.0 – 1.25`：加力区，显示 `A/B`
- `< 0.04`：减速板，显示 `BRK`

`THR_MAX = 1.25` 定义在 `game.js`。插值前会在 `stepAircraft()` 里
夹回 0..1，是否加力由 `a.ab` 单独决定——这样 AI 只设 `throttle`(0..1)
和 `ab` 也能正常工作。

### 中心

- **机头参考**（绿色十字）：机身实际指向
- **速度矢量**（青色小圆 + 三须）：1400 m 外的投影点，即"飞机在往哪飞"
- **机炮准星环**（虚线圆）：提示机炮大致落点

机头参考与速度矢量**分开**是有意的：两者的夹角就是迎角，
在机动中能直观看出"机头指向"和"实际航迹"的差异。

### 速度带 / 高度带

- 速度：`scale 0.85`，每 50 m/s 小刻、200 大刻。左带同时显示 km/h 和 kt
- 高度：`scale 0.021`，每 1000 m 小刻、5000 大刻
- 当前值用三角形指针标出

`tape()` 的 `scale` 参数决定"多少米算一格像素"。改它之前先想清楚
一米对应多少像素。

### 动压表（本作特有）

右下方一个方框，显示当前 `Q` 值（kPa）与一条量程 60 kPa 的条，
20% 处有一道红色警戒线（对应 12 kPa）。

- `Q < 20` 转琥珀
- `Q < 12` 转红并闪烁"舵面失效"

**这是玩家在 18 km 以上唯一的生命线**，不要挪走或缩小。

### 雷达

左下角圆形，**机头朝上**（heading-up）。

坐标转换（`radarXY()`）：

```js
rx = dx * fwd.z - dz * fwd.x;     // 右
ry = dz * fwd.z + dx * fwd.x;     // 前
```

符号容易搞错，验证方法：机头朝北时，北方的目标应该出现在正上方。

范围 12 km。超出范围的显示在环上（`out: true`）。

### 威胁环（RWR）

右下角同心圆，把威胁方向投影到环上：

- 圆圈 + 实心点：有雷达在照射，或导弹在接近
- 红圈：距离 < 2600 m
- 顶部文字：`▲ 导弹逼近`（红，闪烁）/ `▲ 被照射`（琥珀）

### 目标框与 NEZ

**锁定框恒为红色**，它只表达一件事：这是个敌人。

早期版本写的是 `inNez ? RED : GREEN` —— 一进 NEZ 整个框就换色，
读起来像是换了目标，而不是"情况变了"。现在 NEZ 用**修饰**表达：

| 状态 | 外观 |
|---|---|
| 未锁定敌机 | 半透明红细框 |
| 已锁定 | 红色四角括号 |
| **进入 NEZ** | 括号**内侧再叠一层短括号**（视觉上收紧）+ 外面套一圈细环 + 线宽加大 |

地面与浮空目标用灰蓝色 —— 那是在区分**目标类型**，与敌我无关，不冲突。

**机型代号**：锁定框右侧数据块的第一行是呼号，第二行是机型
（`C-14 旗鱼`）——效仿皇牌空战，红框旁边直接写清那是什么飞机。

数据块的行高由 `ly` 递推，不再逐行写死 y 偏移（之前想在中间插一行，
得手工挪后面所有的数字）。

### 来袭导弹

导弹是唯一能真正杀死玩家的东西，而它在屏幕上只是一个小亮点，
钻进云里就彻底看不见了。所以每一枚**以本机为目标**的导弹都会被标出：

- 在屏幕内：红色菱形 + 距离（1 km 内显示米，否则显示公里）
- 在屏幕外：贴到屏幕边缘画一个指向它的箭头 + 距离，1.4 秒周期闪烁

### 目标框与 NEZ（旧标题位）

被锁定的目标有四角括号 + 数据块（名称、距离、高度差、目标 Q 值）。

**NEZ 实环**：`computeNEZ()` 每帧估算不可逃逸区，目标处于其中时
整个框变红并显示 `NEZ`。

NEZ 估算不是很精确的导弹仿真，而是：

```js
effRange = speed * life * powerK;          // 有效动力距离
escape   = targetSpeed * life * powerK * 0.42;   // 目标能跑掉的距离
nez      = effRange - escape - closing * 1.1;
```

`powerK` 对冲压弹在 18 km 以上取 0.26。

屏幕外的目标在边缘显示箭头 + 距离。

### 指南针

顶部水平带，显示当前航向 ±50°。

- 每 5° 短刻，每 10° 标注，N/E/S/W 高亮
- 中心琥珀三角 = 当前航向，下面有三位数字读数
- **任务目标方位标记**（琥珀小三角）：这是 M2 里找到浮空平台的
  主要手段

**为什么必须有它**：早期版本没有指南针，海面是单一颜色，
玩家滚转后完全分不清自己在往哪转。指南针 + 云的视差
共同解决方向感问题。

### 武器面板（底部中央）

左右两侧是固定的 `GUN 备弹` 与 `DECOY 组数`，中间是**挂载武器纵列表**：

> `DECOY` 就是干扰弹 —— **热焰弹与箔丝**的合称。前者骗红外、后者骗雷达，
> 实际投放时两者一起撒，所以座舱里只给一个词。单位是**组**，按住 V 连续投放。

```
      > TOR-2    8  R2
        GIR-9    4  R2
```

- 当前选中的那一行左边有 `>`，用琥珀色
- 数字是余弹，归零转红；`R2` 表示一次齐射打 2 枚
- `R` 键循环切换

**为什么是纵列表**：挂载系统让玩家可能同时带 3–4 种武器
（见 [loadout.md](loadout.md)），只显示"当前那个"会让玩家
完全不知道按 R 能切到什么、还剩多少。列表必须一次全看见。

ECM 显示剩余生效时间，DEW 显示充能数（◆◇）。下面是 HULL 条。

### 目标方位尺（屏幕中下）

锁定目标**跑出视野**时，屏幕边缘那个小箭头太容易被云和地面网格淹没。
所以在中下方（`H*0.82`）额外给一条方位尺：

- 中间朝上的小三角 = 机头方向
- 目标标记的**左右偏移** = 方位角，**上下偏移** = 俯仰角
- 左右两端显示距离与 `L/R` 读数

目标在侧后方时方位角没有意义，标记直接顶到左右边缘。

### 告警（屏幕中上部 y≈110）

按优先级垂直排列，全部闪烁：

`STALL 失速` → `TERRAIN 地形告警` → `LOW Q 动压不足` → `WINCHESTER 弹药耗尽`

## 输入映射

| 输入 | 作用 | 代码位置 |
|---|---|---|
| 鼠标移动 | 引导机头指向（默认） | `updateMouseAim()` |
| `M` | 切换鼠标引导 / 键盘直控 | `toggleAimMode()` |
| `W`/`S` | 抬头 / 低头 | `controlPlayer()` |
| `A`/`D` | 左滚 / 右滚 | 同上 |
| `Q`/`E` | 方向舵 | 同上 |
| `Shift`/`Ctrl` | 油门杆（推满自动进加力，收到底自动张减速板） | 同上 |
| `X`/`Z` | 直接推到底 / 收到底 | 同上 |
| `↑↓←→` | 自由视角（回中） | `updateCamera()` |
| 左键 / `Space` | 机炮 | `controlPlayer()` |
| 右键 / `Enter` | 特殊武器 | `fireSpecial()` |
| `F`/`Tab` | 切目标 | `cycleTarget()` |
| `R` | 切挂载 | `cycleSpecial()` |
| `V` | 干扰弹 | `Ent.breakLock()` |
| `C` | 切视角 | `camMode` |
| `1`/`2`/`3` | 僚机指令 | `setWingCmd()` |
| `H` / `Esc` | 暂停 | `togglePause()` |

**鼠标引导**：`updateMouseAim()` 把屏幕点转成世界方向，
再交给 `AI.steerTo()`（和 AI 同一个控制律，见 [ai.md](ai.md)）。

鼠标位置是**绝对屏幕坐标**，不锁指针——推到边缘就是最大持续转弯率。

## 设置系统

### 数据驱动

`SET_GROUPS` 描述所有设置项，`buildSettingsInto(container)` 把
任意容器填满控件。**独立设置页和暂停菜单里的设置页共用全部代码。**

加一个设置项 = 往 `SET_GROUPS` 加一行 + 在 `DEFAULTS` 加默认值。

### 各项

| 键 | 默认 | 说明 |
|---|---|---|
| `volMaster` | 45 | 主音量 |
| `volEngine` | 45 | 引擎音量（相对）。**默认压低**，因为引擎是持续音 |
| `volSfx` | 85 | 音效音量 |
| `muted` | false | 全部静音 |
| `fov` | 56 | 视场角 |
| `camDist` | 74 | 镜头距离（原值 96，太远） |
| `camHeight` | 22 | 镜头高度 |
| `hudOpacity` | 100 | HUD 透明度 |
| `compass` | true | 顶部指南针开关 |
| `targetMarkers` | true | 目标方位标记开关 |

### 持久化

`localStorage` 键 `monsoonline.settings.v1`。读写都包在 try/catch 里，
无痕模式或禁用存储时静默降级到默认值。

**改设置项名称时记得升版本号**，否则老存档里的值会被静默丢弃
（`loadSettings()` 只接受 `DEFAULTS` 里存在的键）。

### 热调整

暂停时 `update()` 不跑但 `render()` 照跑，所以拖动视角滑块能立刻
看到画面变化。**这是把设置嵌进暂停菜单的全部理由。**

## 暂停菜单

三个页签：

- **暂停**：继续 / 放弃任务
- **设置**：与独立设置页完全相同的控件
- **操作说明**：`buildHelpHTML(true)` 生成的单栏版本

页签切换由 `switchPauseTab(name)` 处理。

**操作说明是单一数据源**：`KEYMAP` 和 `TIPS` 两个数组同时喂给
独立手册页和暂停菜单。早期这里是两份独立的 HTML，改一个忘一个。
