# 飞行模型与大气

代码：`js/entities.js` · 数据：`js/data.js` 的 `phys` 字段

---

## 一句话概括

**动压 `q = ½ρv²` 是这个游戏唯一的物理主角。**
它同时决定三件事：操纵面有多灵、导弹能拐多急、机炮能打多远。

这不是为了拟真而拟真——见 [world/SETTING.md](../world/SETTING.md)。
平流层作战的设定需要一个能算出来的支点，动压就是那个支点。

---

## 标准大气

`airDensity(y)` 实现 ISA 分层模型：

| 高度 | 密度 (kg/m³) | 相对海平面 | 压强 |
|---|---|---|---|
| 0 m | 1.225 | 1.00 | 101.3 kPa |
| 11 000 m | 0.3639 | 0.30 | 22.6 kPa |
| 18 000 m | 0.1216 | 0.10 | 7.6 kPa |
| **20 000 m** | **0.0880** | **0.072** | **5.5 kPa** |
| 22 000 m | 0.0550 | 0.045 | 4.0 kPa |

- 0–11 km：对流层，`T = 288.15 - 0.0065y`，`ρ = 1.225(T/288.15)^4.2561`
- 11–20 km：等温层，`ρ = 0.3639 · exp(-(y-11000)/62188.6)`
- 20–32 km：升温层，指数按 `-35.16`

**这三段的常数是怎么来的**：全部来自标准大气定义，不是调出来的。
改之前先算一遍 20 km 处应该是 0.0880。

## 动压与控制权限

```js
q = 0.5 * airDensity(y) * speed * speed;     // Pa

// 操纵面权限：22 kPa 时满权限，低于此线性衰减到 13%
ctrl = clamp(q / 22000, 0.13, 1.0);
```

HUD 上的 `Q` 表显示 kPa，**12 kPa 以下开始告警**（`ctrl ≈ 0.55`）。

**这个系数乘在角速度上**，所以同一架飞机在海平面 300 m/s 和
20 km 高度 300 m/s 的操纵性差了一个数量级。

### 三架机的数值差

| | vMax | vStall | accel | pitch | roll | hp |
|---|---|---|---|---|---|---|
| DB-11 军舰鸟 | 480 | 105 | 26 | 0.60 | 3.0 | 130 |
| D-14 旗鱼 | 566 | 122 | 33 | 0.63 | 3.4 | 92 |
| G-6 鲣鸟 | 380 | 88 | 18 | 0.50 | 2.2 | 250 |

单位：m/s、m/s²、rad/s。

**D-14 的设计逻辑**：失速速度最高（122 m/s）、结构最脆（92），
但在 20 km 高度因为推力衰减的补偿算得最好，是唯一能在那里
维持 M2.0 机动的机型。**它的强项和弱点都是"高空"**。

## 姿态积分

飞机姿态是三个正交基，每帧做局部旋转（罗德里格斯）：

```js
抬头：绕 right 轴转 -θ
右滚：绕 fwd   轴转 -θ
右偏航：绕 up  轴转 +θ
```

**符号为什么是负的**：`rotAxis` 用的是右手定则。绕 `right` 正向旋转
会让机头向下（`forward` 从 `(0,0,1)` 变成 `(0,-sinθ,cosθ)`），
所以"抬头"要取负。滚转同理。

每帧末尾用 `M3.orthonormalize()` 修正累积漂移。

**不要改成欧拉角**：垂直姿态有万向节锁，而这个游戏有大量垂直机动。

## 速度模型

```js
vTarget = lerp(vStall * 0.74, ab ? vMax : vMil, throttle);
vTarget -= fwd.y * 52;                       // 爬升掉速 / 俯冲增速
vTarget = max(vTarget, vStall * 0.52);

if (y > 11000) {                             // 高空推力衰减
  k = clamp(1 - (y - 11000) / 15000, 0.20, 1);
  vTarget = lerp(vStall * 0.55, vTarget, k);
}
speed += clamp(vTarget - speed, -acc*dt, acc*dt);
```

高空衰减到海平面的 **20%**——这是自适应循环发动机的物理依据
（见 [world/SETTING.md](../world/SETTING.md) 的发动机一节）。

减速板（`brake`）会把目标速度压到 `vStall * 0.92` 并把减速率乘 1.8。

## 可变后掠翼

只有 DB-11 军舰鸟有（数据里的 `variableSweep: true`）：

```js
a.sweep = clamp((a.speed - 170) / 250, 0, 1);   // 0 = 展开，1 = 后掠
```

渲染时 `pushModel()` 按 `opts.sweep` 在**展开位**与**后掠位**两套顶点之间
插值（模型数据里的 `morph.map / spread / swept`）。后掠位约 35°，展开位约 11°。

**为什么做成真变形而不是删掉这个设定**：变后掠是 DB-11 唯一的辨识特征，
而顶点插值成本很低 —— 只在 `pushModel` 的顶点循环里加一次线性插值。

**加新机型时**：只有带 `morph` 数据的模型才响应 `opts.sweep`，
其他机型传什么都不影响。

## 挂载重量

见 [loadout.md](loadout.md#重量惩罚)。在 `stepAircraft()` 里对机型物理数据
做临时缩放，**AI 没有 `loadFactor` 所以完全不受影响**。

## 失速

`speed < vStall` 时：

1. `ctrl` 再乘 0.34（舵效雪上加霜）
2. 施加低头力矩，机头自动下沉

不做"完全失控"——这是街机游戏，玩家应该被惩罚但不该被缴械。

## 导弹动力学

### 导引品质：`lead` 字段

```js
tGo  = dist / max(60, missileSpeed);
lead = weapon.lead;                      // 0 .. 1
aim  = target.pos + target.vel * tGo * lead;
desired = normalize(aim - missile.pos);
```

`lead` 是**这枚弹聪不聪明**的唯一参数：

| lead | 行为 |
|---|---|
| `0` | 纯追踪 —— 傻追目标当前的位置，你一拐弯它就绕到失速 |
| `0.4` | 基础弹水平（TOR-2 是 0.38） |
| `0.9` | 飞向解算出来的最优拦截点，怎么拐都还在它前置量里（DAR-12） |

**这个数字比转弯率更能体现导引能力**。一枚转弯率一般但预测准的弹，
打机动目标反而比一枚只会死咬尾巴的灵活弹更管用：
灵活性买的是"最后一刻的修正"，预测能力买的是"从头就没错"。

早期的实现是所有人共用 `0.82` 的固定折扣，于是"导引好"和"导引差"
只能靠转弯率区分——那只影响最后一秒，不影响整条弹道。

**加新导弹时别忘了给 `lead`**，`smoke.js` 会检查制导武器是否都有这个字段。

### 转弯能力受动压限制

```js
turnFactor(y) = max(0.34, sqrt(airDensity(y) / 1.225));
maxTurn = weapon.turn * turnFactor(y) * dt;
```

**20 km 高度时 `turnFactor ≈ 0.27`**（下限 0.34 兜底）。

所以一枚海平面 3.4 rad/s 的格斗弹，在 20 km 只剩约 1.16 rad/s——
**这就是"高空导弹退化成一门有制导的炮"的实现**。

### 转弯消耗动能

```js
var used = min(want, maxTurn) / dt;          // 实际转弯率 rad/s
var load = clamp(used / 3.0, 0, 1);
m.speed = max(170, m.speed - load * 62 * dt);
```

**没有这一条，"躲导弹"在物理上就不可能**：导弹在动力段之外照样能满过载
无限机动，玩家的桶滚和 3/9 线规避全都没有意义——因为对手不累。

现在满过载转弯 0.5 秒掉约 70 m/s。这是"拖垮导弹"能成立的前提。

### 视场与丢失

目标偏出 ±75°（`off > 1.35 rad`）持续 0.5 秒 → `seekerOn = false`。

V-11 锥刺有 `reAcquire`：丢失后会搜索 2.6 km 内的敌机重新锁定一次。

### 动力段

```js
powered = age < effectiveLife(w, y)
```

`effectiveLife` 对**冲压弹**（`scramjet: true`）特殊处理：
18 km 以上因缺氧，动力段从 10 秒缩到 2.4 秒。

## 子弹

```js
vel.y -= 9.8 * dt;      // 只有重力，忽略空气阻力
pos += vel * dt;
```

命中检测用 `M3.raySphere()` 对**上一帧到当前帧的线段**求交——
子弹速度 1100 m/s，60 fps 下每帧走 18 m，点检测会漏掉目标。

**注意**：`fireGun()` 用 `gunTimer` 按射速节流，不要每帧无条件调用。

## 定向能拦截

在 `game.js` 的 `updateDEW()`。每帧判定：

```js
chance = (y > 18000 && w.highAltChance) ? w.highAltChance : w.interceptChance;
if (random() > chance * dt / 1.2) continue;   // 折算成每帧概率
```

`dt / 1.2` 是把"整个拦截窗口内 55% 成功率"折算成每帧概率，
窗口长度按导弹在这段距离的飞行时间（约 1.2 秒）估算。

**改这个公式要同时想清楚**：现在 `chance=0.55` 对应的实际成功率
大约就是 55%，因为 1.2 秒的窗口里累积接近一次完整判定。
