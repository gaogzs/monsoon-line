# 机体命名由来（开发笔记）

这些文字原来写在资料库里的机体描述（`locales/zh-CN/text/aircraft/<id>.json` 的 `desc`）的开头，
属于「为什么叫这个名字」的设计说明，**不该出现在游戏里**，所以从描述里移出，收在这里。
以后写新机型的描述时，命名原因也写在这份笔记里，不写进 `desc`。

命名规则见设定集（`SETTING.md` 的命名一节）：上游飞机用海鸟 / 海鱼，下游飞机用岩石 / 矿物。

| 机型 id | 名字 | 命名由来（原文） |
|---|---|---|
| `booby` | 鲣鸟 G-6 | 鲣鸟是一种以将近 100 公里时速俯冲入水的海鸟。上游公约的命名委员会在这件事上没花什么心思。 |
| `skua` | 贼鸥 D-21 | 正面雷达反射面积大约相当于一只海鸟 —— 名字就是这么来的。（描述里只保留了「相当于一只海鸟」这个设计事实） |
| `gannet` | 塘鹅 F-12 | 塘鹅是体型最大的海鸟之一，却会从高空折翼垂直扎进水里。命名委员会这次依然没怎么花心思。 |
| `tern` | 燕鸥 G-8 | 燕鸥是一种从高空盯住鱼、折身俯冲下去叼走的海鸟。这一次命名委员会难得没有凑数。 |
| `puffin` | 海鹦 J-4 | 海鹦是一种一嘴能叼十几条鱼的海鸟，长着一张又大又亮的脸。命名委员会这次的想法很直接：这是一架来给别人送东西的飞机。 |
| `manta` | 蝠鲼 J-6 | 蝠鲼是海里最大的鳐，宽扁的身子、圆润的翼、两片朝前探出的头鳍，看上去慢吞吞的，却能一口气游很远。（外形也照着蝠鲼画：飞翼式宽扁机体、头鳍、尾刺） |
| `obsidian` | 黑曜岩 GAL-52 | 黑曜岩是火山玻璃，光滑、乌黑、碎了以后每一片都是刀。高峰军工制造局给这型飞机起这个名字，大概是想说：它自己不动手，但它撑开的那一片东西会割人。 |
