## 这是什么

2078 年，人类在平流层下部部署了一千四百个自主浮空单元，用播撒冰核的方式
微调季风线的落雨位置。这套阵列叫**「调节场」**，它救了很多人。

但它是一个**位移**系统，不是**增量**系统——它不能造雨，只能把本来要下的雨
往北或往南推一小段。十六年来，它每一个周期收到的都是同一条指令：

```
本周期目标：+4 公里
```

于是线北多下了 31% 的雨，线南少了 44%。

偏移量的表决机制写在一份文件的**附件七**里，而附件七从未公开过。
现在有人要把它**转过来**。

你为受益的那一方作战。这个设定不会让你舒服。

## 快速开始

**最快的办法：** 直接打开 <https://gaogzs.github.io/monsoon-line/>。

**本地运行：**

```bash
git clone https://github.com/gaogzs/monsoon-line.git
cd monsoon-line
```

然后直接用浏览器打开 `index.html`。

> 也可以起一个本地服务器（非必需，游戏在 `file://` 下可正常运行）：
>
> ```bash
> python -m http.server 8000
> ```
>
> 然后访问 <http://localhost:8000>

建议用支持 WebGL2 的现代浏览器并按 `F11` 全屏（不支持时会退回 2D 画法，画面效果会少一些）。第一次点击会启用音频。

## 挂载

每架飞机有几组**成对的挂载点**，在机库里一组一组地选装。右侧的挂载选择栏按
**格斗弹 / 雷达弹 / 对地 / 吊舱 / 特殊**分类，侧边的导航按钮点一下就跳到对应分类。

- 每个位置的可选清单不同 —— 翼尖只受得起轻型空空弹，大型弹只有重挂点挂得下；
  挂不了的也会列出来，变暗、打叉并写明原因（挂点类型不符，或机体缺少对应能力）
- 同一种武器挂到多个组上，**弹药池累加、一次齐射的枚数也累加**
- 挂满会拖慢飞机（加速、俯仰、滚转、极速、失速速度都受影响），
  **打出去的弹会让拖累随之减轻**；吊舱不消耗，所以拖累一直在
- **匿踪**：机体自带的匿踪值会缩短敌方对你的锁定距离，外挂每个挂点会折损一点；
  内埋弹舱里的挂载不折损。和它分工的是**电子对抗**，负责削弱来袭导弹的提前量预测
- 连基础短程导弹也是可选项 —— 不带就没有，只能靠机炮

## 操作

游戏默认使用**鼠标引导**（指令增稳飞控）：移动鼠标就是告诉飞控"我想让机头指向哪里"，
滚转、俯仰与协调转弯由飞控解算。

屏幕上的 `CMD` 瞄准环会随动压下降而**张开**——空气越稀薄，飞控越使不上劲。

| 输入 | 作用 |
|---|---|
| **鼠标移动** | 引导机头指向（默认模式） |
| `M` | 切换 鼠标引导 / 键盘直控 |
| `W` / `S` | 拉杆抬头 / 推杆低头 |
| `A` / `D` | 左滚 / 右滚 |
| `Q` / `E` | 方向舵 |
| `Shift` / `Ctrl` | 油门增 / 减 |
| `X` / `Z` | 加力燃烧室 / 减速板 |
| `↑↓←→` | 自由视角（松开自动回中） |
| `鼠标左键` / `Space` | 机炮 |
| `鼠标右键` / `Enter` | 发射特殊武器 |
| `F` / `Tab` | 切换目标 |
| `R` | 切换挂载 |
| `V` | 释放干扰弹 |
| `N` | 电磁静默 EMCON（关雷达 / 断数据链 / 停辐射） |
| `C` | 切换视角（追尾 / 座舱 / 目标） |
| `1` `2` `3` | 僚机指令：散开 / 集火 / 掩护 |
| `H` | 暂停 |

## 它特别在哪

### 平流层作战

整个战役里有三个阶段发生在 **18 000 – 22 000 米**。这不是为了好看——那个高度的
物理学是整个设计的支点：

| 高度 | 密度（相对海平面） | 静压 |
|---|---|---|
| 0 m | 1.00 | 101.3 kPa |
| 11 000 m | 0.30 | 22.6 kPa |
| **20 000 m** | **0.072** | **5.5 kPa** |

- **动压 `q = ½ρv²`**：20 km 高度要获得同等动压需要 **3.7 倍**速度。HUD 上有独立的
  `Q` 表，低于 **12 kPa** 开始告警，操纵面权限会实时下降
- **导弹过载崩塌**：所有导弹的转弯能力按 `√(ρ/ρ₀)` 缩放。海平面上有 40G 的格斗弹，
  在两万米只剩 6–9G——**导弹在高空退化成一门有制导的炮**
- **机炮反而更强**：炮弹不需要空气来转向，只需要空气来保持弹道。20mm 的有效直射距离
  从海平面的 1200 米变成 20 km 高度的 **2600 米**

所以"高端未来空战回到机炮"这件事，在这个游戏里有一个能算出来的理由，
而不是靠怀旧。

### 装备编号用的是真实的逻辑语（Lojban）词根

架空世界的**签字语言**是逻辑语——一门为消除歧义而造的人工语言。
跨国气候工程里的一次误读，代价是几千万吨雨落在错误的纬度上，
而后果要九个月后才显现。

装备制式编号的前缀全部取自**真实的**逻辑语词根，不是随手拼的字母：

| 编号 | 词根 | 源词 | 含义 |
|---|---|---|---|
| `CEL-` | cel | *cecla* | 发射器 / 炮 |
| `SUT-` | sut | *sutra* | 快 |
| `PEJ-` | pej | *preja* | 扩散 / 播撒 |
| `GUS-` | gus | *gusni* | 光 |
| `ZUN-` | zun | *zunti* | 干扰 |
| `BAD-` | bad | *bandu* | 防卫 |
| `CAV-` | cav | *carvi* | 雨 |
| `DIL-` | dil | *dilnu* | 云 |

完整对照表见游戏内资料库，或 [世界设定集 7.6 节](docs/world/SETTING.md)。

> **注意**：逻辑语只用于书面与编号，不用于通话。没有一个飞行员能流利地说它——
> 它负责让文件不出错，不负责让人互相理解。

### 敌人在用消失的村庄名做呼号

下游航空军有一个违反常规的做法：飞行员用**村庄名**做呼号。
这些村庄全部位于调节场的降水负偏移区内，其中 4100 多个已经在统计上
"不再有稳定降水"。

当你的 RWR 上出现一个双机编队时，敌我识别会告诉你两个词：**「沙口」和「干井」**。

你不会在航图上找到它们。

## 技术说明

- **手写的 WebGL2 渲染**：没有 Three.js，没有任何库。模型面、天空、海面、云和粒子
  共用一个深度缓冲，着色规则在 `shading.js` 里只写一份；曳光与 HUD 画在 2D 画布上。
  浏览器不支持 WebGL2 时退回原来的 Canvas 2D 管线（透视投影、近平面裁剪、画家算法排序）
- **画风**：每个面一个颜色（flat shading），低多边形，距离大气透视
- **飞机姿态用正交基积分**（罗德里格斯旋转）而非欧拉角，避免万向节锁
- **相机用位置 + 三个正交基向量**而非矩阵
- **无任何外部资源**：没有图片、没有音频文件、没有字体文件。音效全部由 WebAudio 实时合成
- **性能手段**：每帧对象池、颜色量化缓存、屏幕面积极小的面剔除

## 开发

```bash
node tools/smoke.js
```

这是项目唯一的自动化测试：用最小 DOM / Canvas / WebAudio 桩把所有脚本
加载起来，跑一遍开机自检，逐个点击导航按钮，启动任务并推进 240 帧。
**改完代码先跑它。**

发一个新版本：

```bash
node tools/release.js vX.Y.Z
```

版本号由人指定（规则见 [版本号规则](docs/VERSIONING.md)）。脚本会把这一批提交
追加进 `CHANGELOG.md`，并刷新游戏读的 `js/changelog.js` 与主菜单上的版本戳。
剩下要你做的只有一件事：把生成的"待润色"标题改成一句人话。

游戏本身还有一层**运行时自检**（`preflight()`）：模块加载失败或数据引用了
不存在的模型/武器时，屏幕底部会弹出红色提示条列出问题。
如果你打开游戏后看到了红条，请把上面的内容提一个 issue。

文档在 [`docs/`](docs/README.md)。**改代码时请同步更新对应文档**——
里面记的都是"为什么这么做"，不写下来就会在半年后被改回去。
